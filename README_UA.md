# Трекер цін кейсів CS2

<p align="center">
  <a href="README.md">English</a> •
  <strong>Українська</strong>
</p>

Відстежує ціни CS2 (Counter-Strike 2) на торговому майданчику Steam і оновлює колонку **Now price** у вашому портфелі в Google Таблицях. Підсумки та прибуток/збиток рахують формули самої таблиці.

Також може працювати як [Telegram Mini App](#telegram-mini-app): мінімалістичний трекер портфеля просто в Telegram.

## Можливості

- 🔍 **Пошук і додавання предметів**: вибираєте точний предмет зі списку результатів пошуку. Спершу шукаються контейнери (кейси, капсули), потім усі предмети.
- 📊 **Оновлення цін**: разово (зручно для cron / Планувальника завдань) або в циклі.
- 💱 **Ваша валюта**: ціни записуються в налаштованій валюті (UAH, USD, EUR, …), і валюти ніколи не змішуються непомітно.
- ⚡ **Економія квот**: один запит до Steam на предмет і один запис у Google Таблиці за оновлення. Ліміти Steam обробляються з очікуванням і повторами.
- 📈 **Історія цін (опційно)**: кожне оновлення може дописувати рядки на вкладку *History*, з якої зручно будувати графіки.

## Вимоги

- Python 3.10+
- Акаунт Google і проєкт у Google Cloud (безкоштовного тарифу достатньо)

## Встановлення

```bash
git clone https://github.com/Zenzoik/CS2-price-checker.git
cd CS2-price-checker
pip install -r requirements.txt
```

Можна також виконати `pip install .`: тоді з'явиться команда `cs2tracker`.

## Налаштування

### 1. Скопіюйте шаблон таблиці

1. Відкрийте [шаблон таблиці](https://docs.google.com/spreadsheets/d/1eShxZQ34gI8dir-6LISCNX-omjF8A2XQJb9vL1jh_bs/edit?usp=sharing).
2. **Файл → Створити копію** і назвіть копію `Template_CS_2_cases`. Можна й інакше, якщо вказати `spreadsheet` у конфігу.

### 2. Створіть сервісний акаунт Google

1. У [Google Cloud Console](https://console.cloud.google.com/) створіть проєкт або виберіть наявний.
2. У **APIs & Services → Library** увімкніть **Google Sheets API** і **Google Drive API**.
3. У **APIs & Services → Credentials** натисніть **Create Credentials → Service Account**. Назва будь-яка, ролі пропустіть, потім натисніть **Done**.
4. Відкрийте сервісний акаунт, перейдіть у **Keys → Add Key → Create new key → JSON** і збережіть файл як `service-account.json` у папці проєкту.

### 3. Надайте доступ до таблиці

Відкрийте свою копію таблиці, натисніть **Надати доступ**, вставте email сервісного акаунта (`client_email` у JSON-файлі, на кшталт `name@project.iam.gserviceaccount.com`), виберіть роль **Редактор** і зніміть «Сповістити людей».

### 4. Конфіг (опційно)

Усі параметри мають значення за замовчуванням, тож цей крок необов'язковий. Щоб щось змінити:

```bash
cp config.example.toml config.toml
```

| Ключ | За замовчуванням | Значення |
|------|------------------|----------|
| `credentials` | `service-account.json` | Шлях до ключа сервісного акаунта |
| `spreadsheet` | `Template_CS_2_cases` | Назва таблиці, повний URL або ключ |
| `worksheet` | `0` | Індекс вкладки (0 = перша) або її назва |
| `name_column` / `price_column` | `A` / `C` | Колонки з hash name і з ціною для запису |
| `currency` | `UAH` | ISO-код або `auto` (валюта Steam для вашого IP) |
| `price` | `sell` | `sell` = найнижчий лот, `buy` = найвищий ордер на купівлю |
| `interval_minutes` | `5` | Інтервал між оновленнями в режимі `watch` |
| `request_delay` | `1.5` | Мінімальна пауза між запитами до Steam, с |
| `history_worksheet` | *(вимкнено)* | Назва вкладки для історії, напр. `History` |

## Використання

```bash
python main.py                        # меню: 1 додати, 2 відстежувати, 3 вихід, 4 оновити раз
python main.py add "breakout case"    # пошук і вибір зі списку
python main.py add -y "chroma 2 case" "prisma case"   # взяти перший результат
python main.py search "sticker capsule" --all-items   # подивитися, не змінюючи таблицю
python main.py update                 # оновити ціни один раз
python main.py update --dry-run       # отримати й показати ціни, нічого не записуючи
python main.py watch -i 10            # оновлювати кожні 10 хвилин до Ctrl+C
```

Після `pip install .` замість `python main.py …` можна писати `cs2tracker …`.

**Buy price (B)** і **Quantity (E)** заповнюєте ви. Скрипт записує лише **Hash name (A)** і **Now price (C)**.

### Запуск за розкладом

`update` виконується один раз і завершується, тож тримати термінал відкритим не потрібно. Нехай його запускає система:

- **macOS / Linux (cron)**: `*/15 * * * * cd /path/to/CS2-price-checker && /usr/bin/python3 main.py update >> tracker.log 2>&1`
- **Windows**: у Планувальнику завдань створіть завдання `python main.py update`, у полі *Робоча папка* вкажіть папку проєкту.

Коди виходу: `0` означає, що все гаразд, `2` — частину предметів не вдалося оновити або Steam був недоступний (див. лог), `1` — помилка налаштування (аргументи, конфіг, ключ, доступ до таблиці), `130` — зупинено через Ctrl+C.

Ціни записуються за назвою предмета, тож сортувати таблицю під час оновлення безпечно. Якщо Steam недоступний, оновлення зупиняється після 3 невдалих предметів поспіль, а не чекає на кожному.

## Telegram Mini App

Окрім Google-таблиці, трекер може працювати як Telegram-бот із Mini App. Кожен, хто його відкриває, веде власний портфель: шукає предмет на ринку Steam, вказує, скільки купив і за скільки, і бачить поточну вартість портфеля та прибуток. У застосунку одна кнопка дії, ціни оновлюються у фоні.

**Налаштування**

1. Створіть бота в [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Спрямуйте домен на сервер і поставте перед застосунком HTTPS reverse proxy. Telegram відкриває Mini App лише через HTTPS; див. [`deploy/nginx.conf`](deploy/nginx.conf) (з certbot) або [`deploy/Caddyfile`](deploy/Caddyfile) на два рядки.
3. Встановіть із додатковими залежностями: `pip install ".[app]"` (або `pip install -r requirements.txt`).
4. Скопіюйте [`deploy/app.env.example`](deploy/app.env.example) у `/etc/cs2tracker/app.env`. Заповніть `CS2BOT_TOKEN` і `CS2BOT_URL`, а за потреби `CS2BOT_ALLOWED_USERS`, щоб бот був приватним.
5. Запустіть командою `python -m cs2tracker.app` або як сервіс: [`deploy/cs2tracker-app.service`](deploy/cs2tracker-app.service).

Під час запуску бот налаштовує кнопку меню, що відкриває застосунок, і на будь-яке повідомлення відповідає кнопкою **Відкрити портфель**. Мова інтерфейсу (українська, російська чи англійська) береться з налаштувань Telegram користувача.

Усі ціни в одній валюті (`CS2BOT_CURRENCY`, за замовчуванням UAH). База даних запам'ятовує валюту й не запуститься з іншою, тож ціни ніколи не змішуються. Які валюти й типи цін працюють з IP вашого сервера, визначають [ті самі правила](#звідки-беруться-ціни).

## Звідки беруться ціни

Валюту стакана заявок Steam визначає за вашою **IP-адресою**, а стакан — єдине джерело точних цін купівлі/продажу. Тому:

- Якщо `currency` збігається з валютою Steam для вашого IP або стоїть `currency = "auto"`, ціни беруться зі стакана. Це один швидкий запит на предмет, і працюють обидва варіанти: `price = "buy"` і `price = "sell"`.
- Інакше скрипт перемикається на *price overview* Steam у вашій валюті. Там є лише найнижчий лот (`price = "sell"`), і це повільніше, бо Steam дозволяє близько 20 таких запитів за хвилину.
- `price = "buy"` з невідповідною валютою зупиняється з поясненням, а не записує ціни не в тій валюті.

`currency = "auto"` визначає валюту заново під час кожного запуску (у межах одного сеансу `watch` вона не змінюється). Якщо ваш IP може змінитися, наприклад через VPN, вкажіть валюту явно, щоб у таблиці ніколи не змішувалися валюти.

> **Оновлення з 1.x:** старий скрипт записував найвищий ордер на купівлю в UAH, і це більше не працює: Steam прибрав зі сторінки дані, на які спирався скрипт. Нове значення за замовчуванням — найнижчий лот у UAH. Щоб і далі отримувати ціни ордерів, встановіть `price = "buy"` разом із валютою, яку Steam використовує для вашого IP. Якщо це не UAH, повідомлення про помилку назве потрібну валюту.

## Структура таблиці

| Колонка | Вміст |
|---------|-------|
| A | Hash name *(заповнює скрипт)* |
| B | Ціна купівлі *(ви)* |
| C | Поточна ціна *(заповнює скрипт)* |
| D | Поточна ціна мінус комісія Steam |
| E | Кількість *(ви)* |
| F–L | Суми та результати (формули) |
| N–R | Підсумок портфеля (формули) |

## Вирішення проблем

- **`Google service account key not found`**: покладіть `service-account.json` поруч із `main.py` або вкажіть `credentials` у `config.toml`. Обидва файли шукаються спершу в поточній папці, потім поруч із `main.py`.
- **`Cannot open spreadsheet`**: надайте доступ до таблиці email сервісного акаунта (Редактор), перевірте значення `spreadsheet` і те, що Sheets і Drive API увімкнені. URL або ключ працюють, навіть якщо назва інша.
- **`Steam serves order books in EUR for your IP…`**: див. [Звідки беруться ціни](#звідки-беруться-ціни). Використайте `price = "sell"` або вкажіть у `currency` валюту з повідомлення.
- **`rate limited (429)`**: Steam обмежує кількість запитів з одного IP. Скрипт чекає і повторює спробу. Якщо це трапляється постійно, збільште `request_delay` або оновлюйте рідше.
- **`not found on Steam market`**: у колонці A має бути точна назва (hash name) з маркету. Додавайте предмети через `add`, щоб не помилитися.
